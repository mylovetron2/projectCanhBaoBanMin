Native Data Flow (BLOCK_BIN)

So do khoi luong du lieu Native theo file hien tai: startBridge -> RunStreamRead -> Compute -> BLOCK emit.

Nguon: windows/runner/daq_native_bridge.cpp, lib/daq_bridge_client.dart

1) So do khoi chinh

flowchart LR
    A[Flutter MethodChannel startBridge] --> B[HandleMethodCall]
    B --> C[StartBridge]
    C --> D[ParseStartArguments]
    D --> E[worker thread starts RunStreamWorker]
    E --> F[RunStreamRead loop]

    F --> G[DAQmxReadAnalogF64 raw block]
    G --> H[Compute RMS per channel]
    G --> I[Compute FFT per channel]
    G --> J[Decimate Wave step 5]

    H --> K[Build BLK1 binary payload]
    I --> K
    J --> K

    K --> L[EmitBinary to EventChannel]
    L --> M[Dart _parseBinaryEvent]
    M --> N[parse BLOCK_BIN]
    N --> O[DaqBlockFrame]
    O --> P[DataAcquisitionService onBridgeBlockFrame]
    P --> Q[AcquisitionSample with fft wave rms]
    Q --> R[UI setState one time]

2) Payload BLOCK_BIN hien tai

Thu tu Thanh phan So luong Mo ta
1 Header 9 x u32 magic(BLK1), version, sampleRateHz, samplesRead, channelCount, binCount, decimStep, outCount, flags
2 RMS C Gia tri RMS cho tung kenh
3 FFT C x B Magnitude FFT theo channel-major
4 Wave C x O Mau song da decimate, channel-major
Total floats = C + (C x B) + (C x O) + (co the co C x samplesRead neu co raw interleaved) Total bytes = 9 x 4 + (Total floats x 4) O = ceil(samplesRead / decimStep)

C = channelCount, B = binCount, O = outCount.

3) Vi sao van co the nang CPU

Da bo buoc format chuoi lon, nhung van ton chi phi o FFT da kenh, cap phat bo nho payload, va repaint chart khi tan suat block cao.

Neu sampleRate/samplesPerRead qua lon, UI van co the giat khi resize/minimize do backlog event + render.

4) Sequence theo thread

sequenceDiagram
    autonumber
    participant UI as Flutter UI thread
    participant NMain as Native main thread
    participant NWorker as Native worker thread
    participant DAQ as NI-DAQmx driver
    participant Ev as EventChannel
    participant Dart as Dart parser/service

    UI->>NMain: MethodChannel.startBridge(args)
    NMain->>NMain: HandleMethodCall + ParseStartArguments
    NMain->>NWorker: Start RunStreamWorker/RunStreamRead

    loop Moi block du lieu
        NWorker->>DAQ: DAQmxReadAnalogF64(samplesPerRead)
        DAQ-->>NWorker: raw interleaved samples

        NWorker->>NWorker: Compute RMS per channel
        NWorker->>NWorker: Compute FFT per channel
        NWorker->>NWorker: Decimate Wave(step=5)
        NWorker->>NWorker: Build BLK1 binary payload

        NWorker->>Ev: EmitBinary(Uint8List)
        Ev-->>Dart: Uint8List event
        Dart->>Dart: ByteData parse header + float blocks
        Dart->>Dart: Build DaqBlockFrame
        Dart-->>UI: AcquisitionSample(fft+wave+rms)
        UI->>UI: setState() + chart render
    end

    UI->>NMain: MethodChannel.stopBridge()
    NMain->>NWorker: stop_requested=true
    NWorker-->>NMain: thread join

Giai doan ton CPU nhieu nhat thuong la: FFT tinh toan trong Native va chart render trong Flutter khi tan suat block cao.

6) Cach lay du lieu va hien thi kenh song

Buoc Thuc hien Du lieu tao ra
1. Start stream Flutter goi startBridge voi channel, sampleRateHz, samplesPerRead. Native mo task DAQmx + bat dau vong doc block.
2. Doc block thuc Native goi DAQmxReadAnalogF64(..., GroupByScanNumber). Mang mau raw interleaved: scan0(ch0..chN), scan1(ch0..chN), ...
3. Tinh toan Tinh RMS tung kenh, FFT tung kenh, va giam mau song voi kDecimStep=5. RMS[C], FFT[C x B], Wave[C x O].
4. Dong goi block Native dong goi nhi phan BLK1 (magic/version/header + float payload). Uint8List gui qua EventChannel.
5. Parse ben Dart _parseBinaryEvent doc header, cat RMS/FFT/Wave/Raw, tao DaqBlockFrame. Block frame day du cho service va UI.
6. Day len service onBridgeBlockFrame tao DaqWaveFrame va day vao stream sample. Sample gom RMS + FFT + Wave.
7. Ve kenh song UI nhan sample, cap nhat _bridgeWaveSamples[channel], user chon Kenh song, ve LineChart. Diem ve: FlSpot(i * timeStepMs, value).
timeStepMs = decimStep / sampleRateHz * 1000 outCount = ceil(samplesRead / decimStep) x(i) = i * timeStepMs, y(i) = channelSamples[ch][i]

Luu y: file nay dang mo ta duong Binary block hien tai (Windows in-process). Che do text BLOCK_MULTI van co the gap tren mot so duong fallback/log cu.
